# 🍜 Momo's Kafe – Restaurant Website

Momo's Kafe is a responsive restaurant website developed using **HTML5, CSS3, JavaScript, and Bootstrap 5**. The website features an attractive food-themed design that showcases the restaurant's brand and creates a user-friendly browsing experience.

### ✨ Features
- **Responsive Navigation Bar:** Easy navigation across Home, About Us, Typography, and Contacts sections.
- **Hero Section:** An attractive banner featuring delicious momos, promotional text, and a call-to-action button.
- **Food Background Images:** High-quality food imagery to enhance the visual appeal of the website.
- **Image Slider:** Navigation controls to browse promotional banner slides.
- **Menu Button:** A call-to-action that allows visitors to explore the restaurant's menu.
- **Bootstrap 5 Layout:** Responsive components and grid utilities for different screen sizes.
- **Clean UI Design:** Attractive typography, spacing, and colors for a restaurant-themed experience.

### 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript
- Bootstrap 5

### 🎯 Project Objective
The objective of this project is to build a visually appealing, responsive restaurant website while practicing Bootstrap 5 components, layout utilities, navigation, and front-end web development.

### 🚀 How to Run
1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Run `index.html` using Live Server.
4. View the website in your browser.
